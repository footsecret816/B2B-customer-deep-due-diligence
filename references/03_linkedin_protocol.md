# 03｜LinkedIn 固定调查协议

## 公司页

固定查询：

1. `"<公司名>" LinkedIn`
2. `site:linkedin.com/company "<公司名>"`
3. `site:linkedin.com/company "<品牌名>"`（有品牌名时）
4. `site:linkedin.com/company "<官网域名>"`

字段：

- LinkedIn Company Page
- Company Name
- Industry
- Company Size
- Headquarters
- Founded
- Followers
- Website
- Specialties
- Latest Public Activity

## 管理层

默认搜索：

- CEO
- Owner
- Managing Director

如三者均未找到且客户重要，可在 L3 扩展：Founder / President / General Manager。

## 采购 / 品类岗位

L2 固定尝试五组：

1. Buyer
2. Purchasing / Procurement
3. Sourcing
4. Category Manager
5. Product Manager

查询格式：

`"<公司名>" "<职位>" LinkedIn`

五组必须全部尝试。

输出：

- Name
- Job Title
- Role Type
- Current Company
- Relevance：HIGH / MEDIUM / LOW
- Evidence
- Status

不得仅凭职位名称断言其拥有最终采购决策权。

## 登录限制

- 公开搜索只找到部分信息：`PARTIAL`
- 登录墙阻挡：`BLOCKED`
- 不得因为平台不可访问而伪造人员。
