# 04｜四大社媒固定扫描协议

所有 L2 客户固定扫描：

- Facebook
- Instagram
- YouTube
- TikTok

## 第一步：存在性搜索

每个平台至少使用：

- `"<公司名>" <平台名>`
- `"<品牌名>" <平台名>`（品牌已知）
- `site:<平台域名> "<公司名>"`

## 第二步：官方身份确认

检查：

- 账号名称
- Logo / 品牌视觉
- 简介
- 官网链接
- 国家/地区
- 联系方式
- 官网是否反链该账号

状态：

- `CONFIRMED_OFFICIAL`
- `LIKELY_OFFICIAL`
- `UNVERIFIED`
- `NOT_FOUND`

## 第三步：固定字段

- Platform
- Account URL
- Official Status
- Followers / Subscribers（公开时）
- Latest Activity Date
- Posting Frequency
- Primary Language
- Primary Market
- Main Content
- Products Shown
- Retail / Store Signals
- Trade Show / Event Signals

## 第四步：是否深挖

- NOT_FOUND → 停止
- UNVERIFIED → 不做内容结论
- 长期不活跃 → 记录即可
- 活跃 / 中度活跃 → 抽样最近 12 条公开内容或最近 90 天内容，先达到者为准

内容抽样关注：

- 最近推广的产品
- 高频产品
- 新品
- 自有品牌
- 实体门店 / 仓库 / 团队
- 展会 / 活动
- 主要国家与语言
- B2B / B2C 特征

不得把“未找到官方账号”写成“公司没有该平台”。
